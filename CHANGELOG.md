## 1.1.0

Validated from the local 1.1.0-rc.1 development candidate.

- Strict ownership-aware release manifests and descriptor-relative path checks.
- Read-only plans, conservative text merging, verified backups, durable update
  journals, interrupted-operation recovery and guarded rollback.
- Self-contained runtime, one editable starter source, no-clobber new projects,
  and conservative metadata-free v0.5 adoption with external recoverable backups.
- Researcher-adopted Narrative/Workstreams/AST/Specifications/manuscript records,
  stable IDs, independent repository support and same-ID interruption recovery.
- Eleven-section bilingual scientific reports, editable Markdown and staged
  HTML/PDF, explicit math/font/figure validation and preserved revisions.
- Optional Runs, honest provenance boundaries, cross-agent handoffs and
  human-operated HPC command preparation without remote execution.
- Synthetic component/failure/archive acceptance tests, public-content audits
  and clean-source release automation. No arbitrary report length limits.
