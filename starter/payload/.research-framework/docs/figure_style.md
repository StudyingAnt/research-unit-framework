# Project Figure Style

Defaults: PNG 600 dpi at intended display size; vector PDF and editable SVG when
appropriate; Arial 5–7 pt at final size; black text except data-encoded categories.
Label axes, units, scales, transformations, colors, symbols, lines, exclusions and
uncertainty. Preserve measurement-image integrity. A raster image in an SVG/PDF
remains raster evidence. Journal and legibility exceptions need explicit reasons.
A primary evidence table is sufficient when a figure would add no information.
