# Research Project

Open this directory in your assistant and read `AGENTS.md` and
`PROJECT_INSTRUCTIONS.md`. Start **Coordination** to discuss the program, or ask
to plan/resume an explicitly scoped AST task. See
`coordination/COORDINATION.md` and `REPORT_TEMPLATE.md`.

The researcher adopts scientific decisions. Plans, reports and figures provide
continuity across sessions; no chat handoff or extra summary is required.
Existing historical research need not be imported into this project.

Fill project-specific settings in `PROJECT_INSTRUCTIONS.md` and
`framework-project.json`. Scientific code remains in independent `repos/`
checkouts; no project-root Git repository or environment is created automatically.
